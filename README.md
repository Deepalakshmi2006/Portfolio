# Portfolio
A clean, one-page portfolio website showcasing my skills, interests, internship experience, projects, and achievements. Designed with a modern two-column layout for clear presentation, making it easy for recruiters and visitors to view my professional profile.
🌟 Overview

The portfolio features a two-column layout:

A left sidebar with my name, role, profile image, contact details, and quick highlights.
A right section showcasing my Objective, Skills, Areas of Interest, Experience, Projects, Achievements, and more.

This minimal yet impactful design allows visitors to understand who I am and what I can offer within seconds.

✨ Features
Clean and professional resume-style design
Fully responsive one-page layout
Clear section divisions for easy readability
Contact details and quick links
Organized presentation of skills, internship, projects, and achievements
Built with simple, lightweight HTML & CSS (no frameworks)
🛠️ Technologies Used
HTML5
CSS3
Times New Roman and system fonts
Basic layout techniques (flexbox, columns)
